# Daniel Lee

Software engineer at Google, working on Cloud Run. I care a lot about developer experience and making it easy to deploy applications to the cloud.

Previously, I was a lead on Firebase Functions, and before that an SRE at Google.

In my spare time, I love playing with how agentic workloads are deployed - where agents run, where their state lives, and what makes them durable. That curiosity is the thread behind most of my pinned projects below.
